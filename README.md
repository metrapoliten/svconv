# svconv

Потоковая свёртка изображений на SystemVerilog для ПЛИС Gowin: камера OV7670 → перевод в оттенки серого → цепочка свёрток (размытие, выделение границ) → вывод на дисплей.

Целевая плата — Sipeed Tang Primer 20K (Dock ext-board), разрешение обработки 160×120. Ядро свёртки не зависит от платы и параметризуется размером кадра и ядра, поэтому должно переноситься на Tang Mega 138K с кадром 640×480.
