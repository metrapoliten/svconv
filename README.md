# svconv

Потоковая свёртка изображений на SystemVerilog для ПЛИС Gowin: камера OV7670 → перевод в оттенки серого → цепочка свёрток (размытие, выделение границ) → вывод на дисплей.

Целевая плата — Sipeed Tang Mega 138K Pro (Dock) с дисплеем 5" 800×480 SH500Q01Z, разрешение обработки 640×480. Ядро свёртки не зависит от платы и параметризуется размером кадра и ядра.
